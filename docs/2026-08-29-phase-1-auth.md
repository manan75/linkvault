# Session: Phase 1 — Setup, API skeleton, Auth (2026-08-29)

Implements the Phase 1 plan from `2026-08-29-overview-architecture.md`. `CLAUDE.md` remains
the source of truth for product and architecture; this records what was built and decided.

## What shipped

- Root scaffolding: `.gitignore`, `.env.example`, `docker-compose.yml` (MongoDB 7), README.
- `server/`: Express 5 + Mongoose, layered as routes → controllers → services → models.
- `client/`: Vite 8 + React 19 + Tailwind 4 + React Router 7, with auth context and route guards.
- Auth end to end: register, login, logout, `GET /api/auth/me`, protected routes.
- 16 backend tests covering validation, hashing, login success/failure, and session handling.

## Decisions made this session

- **Session transport: JWT in an `httpOnly` cookie**, not a bearer token in `localStorage`.
  Page scripts cannot read the token, and it gives logout a real server-side action
  (clear the cookie) rather than a client-only discard.
  Consequence: the client sends `credentials: 'include'` and the API sets
  `cors({ credentials: true })` against a single `CLIENT_ORIGIN`.
- **Vite proxies `/api` to the API in development.** Keeps browser requests same-origin so
  there is no cross-site cookie handling in dev. CORS stays configured for non-proxied callers.
- **No refresh tokens.** One 7-day access token. Revisit when session length becomes a real
  requirement rather than a hypothetical one.
- **Env validated once at startup** (`server/src/config/env.js`, zod). A misconfigured deploy
  fails immediately instead of at the first request that needs the value.
- **`passwordHash` is `select: false`** on the User model, so it is never returned unless a
  caller explicitly asks for it. `toPublicJSON()` is the only shape sent to clients.
- **Login is constant-ish time**: an unknown email is compared against a dummy bcrypt hash so
  response timing does not reveal whether an address is registered. Wrong password and unknown
  email return the identical 401 body.
- **Duplicate email is guarded twice**: a pre-check for the friendly error, and the unique
  index for the actual race. Mongo error 11000 is translated to the same 409.
- **Tests use `mongodb-memory-server`**, so `npm --prefix server test` needs no running database.

## Verified

- `npm --prefix server test` — 16/16 pass.
- `npm --prefix client run build` and `oxlint` — both clean.
- Full auth flow over HTTP against the Docker MongoDB: register 201, me 200, duplicate 409,
  invalid payload 400, logout 204, me-after-logout 401, login 200, wrong password 401,
  unknown route 404. Session cookie confirmed `HttpOnly`.
- Vite dev server boots and proxies `/api` to the API.

Not verified: clicking through the UI in a real browser. The pages build and lint, but the
rendered flow has not been exercised by hand.
